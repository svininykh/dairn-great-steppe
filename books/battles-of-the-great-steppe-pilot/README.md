# Битвы Великой степи — пилот

Пилотная интерактивная книга во вселенной Великой степи.
История «Первое испытание» начинается с поездки Айбике и Қарашаш:
найденное в ковыле украшение становится причиной погони, которая уводит
их далеко от знакомых аулов.
