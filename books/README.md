# Книги DAIRN

В этом каталоге хранятся книги с историями для приложения библиотеки
DAIRN.

Каждая книга размещается в отдельной папке с коротким названием латиницей:

```text
books/
├── assets/
└── book-name/
    ├── README.md
    └── stories/
        └── story-name/
            ├── README.md
            └── chapters/
                ├── 01.md
                └── 02.md
```

- `book-name/README.md` — название и описание книги, автор, языки и порядок
  историй;
- `stories/` — отдельные истории книги;
- `story-name/README.md` — название, описание и порядок глав истории;
- `chapters/` — главы истории в формате Markdown, содержащие описание сцен;
- `books/assets/` — общие для всех книг обложки, иллюстрации и другие
  материалы.

Пример файла главы:

```markdown
# Глава 1. Название главы

## Сцена 1. Название сцены

Описание сцены.

## Сцена 2. Название сцены

Описание сцены.
```

Для языковых версий используется порядок проекта:
**Қазақша / Русский / English**.
