# Планшеты персонажей DAIRN

В этом каталоге хранятся структурные прототипы и будущие варианты
планшетов персонажей для игроков DAIRN.

Прототипы описывают состав и группировку данных, но не задают визуальную
композицию, размеры, графику или способ печати.

- [`player-character-sheet.md`](player-character-sheet.md) — базовый
  трёхъязычный прототип планшета персонажа игрока.
- [`player-character-sheet-kk.md`](player-character-sheet-kk.md) — нұсқа
  қазақ тілінде;
- [`player-character-sheet-ru.md`](player-character-sheet-ru.md) — версия
  на русском языке;
- [`player-character-sheet-en.md`](player-character-sheet-en.md) — English
  version.

Терминология сверяется с [`../glossary.md`](../glossary.md).
