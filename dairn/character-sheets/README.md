# Планшеты персонажей DAIRN

В этом каталоге хранятся структурные прототипы и будущие варианты
планшетов персонажей для игроков DAIRN.

Прототипы описывают состав и группировку данных, но не задают визуальную
композицию, размеры, графику или способ печати.

- [`player-character-sheet.md`](player-character-sheet.md) — базовый
  трёхъязычный прототип планшета персонажа игрока.
- [`player-character-sheet-kk.md`](player-character-sheet-kk.md) — нұсқа
  қазақ тілінде;
- [`player-character-sheet-ru.md`](player-character-sheet-ru.md) — версия
  на русском языке;
- [`player-character-sheet-en.md`](player-character-sheet-en.md) — English
  version.
- [`player-character-sheet-short-ru.md`](player-character-sheet-short-ru.md) —
  краткий планшет для короткой партии без привалов и отдыха:
  Поклажа 3d6, простая таблица для заполнения перед игрой.

Терминология сверяется с [`../glossary.md`](../glossary.md).

## Подготовка краткого планшета

Для коротких партий без привалов и отдыха Поклажа определяется **3d6**:
по одному кубику на Оружие, Дорожное снаряжение и защитное снаряжение
из [существующих таблиц](../tables/starting-inventory-7d6-ru.md).
Результаты не складываются и не переставляются. Вода, Пища, Огонь
и Инструмент в этот набор не входят. Для полной игры сохраняется 7d6.
Характеристики, ОЗ и элементы Жизненного пути определяются отдельно.
Общее Знамение группы записывается на каждом кратком планшете.
