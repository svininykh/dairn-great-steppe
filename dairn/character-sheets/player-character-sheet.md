# Планшет персонажа игрока

Структурный прототип планшета персонажа для **DAIRN: Ұлы Дала Ғаламы**.
Документ определяет состав и смысл разделов, но не устанавливает их
визуальную композицию.

Языковой порядок: **Қазақша / Русский / English**.

## Персонаж

- **Аты / Имя / Name** — имя персонажа;
- **Ойыншы / Игрок / Player** — имя игрока;
- **Өткен / Прошлое / Past** — жизнь и опыт персонажа до начала
  Приключений;
- **Жасы / Возраст / Age** — возраст персонажа;
- **Байланыс / Связь / Bond** — значимая связь с человеком, группой,
  местом или событием Великой Степи.

## Характеристики

- **Сипаттамалар / Характеристики / Ability Scores**;
- **Күш / Сила / Strength (STR)**;
- **Ептілік / Ловкость / Dexterity (DEX)**;
- **Жігер / Воля / Will (WIL)**.

Рядом с каждой Характеристикой предусматривается поле для её текущего
значения.

## Защита и последствия

- **Қорғаныс / Защита (ОЗ) / Hit Protection (HP)** — текущее и
  максимальное значение;
- **Сауыт / Броня / Armor** — значение Брони и её источник;
- **Зиян / Урон / Damage** — временная запись полученного Урона;
- **Ауыр зиян / Критический урон / Critical Damage** — отметка и
  последствия;
- **Тыртық / Тыртықтар** / **Шрам / Шрамы** / **Scar / Scars** —
  полученные Шрамы.

## Состояние и восстановление

- **Қажу / Изнурение / Fatigue** — количество и занятые ячейки;
- **Қажыған / Изнурён / Deprived** — отметка состояния;
- **Тынығу / Отдых / Rest**;
- **Емдеу / Лечение / Healing**;
- **Қалпына келу / Восстановление / Recovery**.

## Поклажа

- **Жүк / Поклажа / Inventory**;
- **Жүк ұяшығы / ячейка Поклажи / Inventory Slot** — десять отдельных
  ячеек;
- **Көлемді / Громоздкий / Bulky** — отметка предметов, занимающих две
  ячейки;
- поля для названия предмета, количества или использований и примечания.

Изнурение отмечается непосредственно в занятых им ячейках Поклажи.

## Опыт и особенности

- опыт и знания, следующие из Прошлого;
- заметные черты внешности и поведения;
- незавершённая история персонажа;
- особые предметы и свойства.

## Книги, Слова и Реликвии

- **Кітап / Книга / Book**;
- **Сөз / Слово / Word**;
- **Жәдігер / Реликвия / Relic**.

Раздел используется только персонажем, у которого есть соответствующие
предметы или знания.

## Путешествие и ресурсы

- **Рацион / Рацион / Rations**;
- **Қорлар / Припасы / Supplies**;
- **Жарық көзі / Источник света / Light Source**;
- сведения о Спутниках, животных и транспорте;
- краткие дорожные заметки.

## Заметки игрока

- текущие цели и решения;
- важные люди, места и события;
- Молва;
- последствия выбора персонажа.

## Термины, требующие закрепления

Термины **Аты / Имя / Name**, **Жасы / Возраст / Age** и
**Байланыс / Связь / Bond** используются в этом прототипе как рабочие.
Перед выпуском планшета их трёхъязычные формы необходимо закрепить в
терминологической базе DAIRN.
