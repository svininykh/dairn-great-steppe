# Материалы DAIRN

В этом каталоге хранятся материалы для настольной ролевой игры
**DAIRN: GREAT STEPPE**, основанные на **Cairn 2e**.

Основные термины проекта закреплены в
[`glossary.md`](glossary.md).

```text
dairn/
├── glossary.md
├── player-book/
├── warden-book/
├── tables/
└── character-sheets/
```

- [`player-book`](player-book/README.md) — Книга игрока: правила и материалы,
  доступные участникам игры;
- [`warden-book`](warden-book/README.md) — Книга ведущего игры: правила
  подготовки и проведения игры, скрытая информация и инструменты ведущего
  игры.
- [`tables`](tables/README.md) — общие таблицы для Книги игрока и Книги
  ведущего игры.
- [`character-sheets`](character-sheets/README.md) — прототипы планшетов
  персонажей для игроков.

Материалы вселенной и собственные правила DAIRN должны быть явно отделены
от правил, заимствованных или адаптированных из Cairn 2e.
