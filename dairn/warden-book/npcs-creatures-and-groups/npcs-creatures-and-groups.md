# Неигровые персонажи, существа и группы

При создании и ведении персонажей мира используются:

- **Ойыншы емес кейіпкер / Неигровой персонаж / NPC**;
- **Ниет / Намерение / Reaction**;
- **Қайрат / Стойкость / Morale**;
- **Жасақ / Отряд / Detachment**;
- **Жолдас / Спутник / Companion**.

Раздел охватывает создание NPC, Намерение, Стойкость, поведение
противников, Отряды, Спутников, животных и ездовых лошадей. Подробные
процедуры будут добавлены по мере разработки.
