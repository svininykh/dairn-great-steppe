# Книга ведущего игры

В этом каталоге хранятся материалы DAIRN, предназначенные для ведущего игры.

Планируемые разделы:

- подготовка и проведение игры;
- устройство и канон мира;
- создание приключений;
- персонажи ведущего и противники;
- места, события и таблицы;
- скрытая информация и инструменты ведущего игры.
