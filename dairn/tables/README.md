# Общие таблицы DAIRN

В этом каталоге хранятся общие таблицы, используемые в Книге игрока и
Книге ведущего игры.

Каждая самостоятельная таблица размещается в отдельном Markdown-файле с
коротким названием латиницей:

```text
tables/
├── equipment.md
├── encounters.md
└── weather.md
```

Названия и игровые термины в таблицах должны соответствовать
[`../glossary.md`](../glossary.md).

## Рабочие таблицы

- [`bonds_d20.md`](bonds_d20.md) — таблица Байланыс / Уз / Bonds с
  выбором результата броском `d20`.
- [`character-traits-8d10.md`](character-traits-8d10.md) — восемь
  таблиц `d10` для определения образа и черт персонажа.
- [`life-path-d20.md`](life-path-d20.md) — рабочая таблица `d20` для
  определения Өмір жолы / Жизненного пути / Life Path персонажа.
- [`omens-d20.md`](omens-d20.md) — таблица Аяндар / Знамений / Omens с
  выбором результата броском `d20`.
- [`scars-d12.md`](scars-d12.md) — таблица Тыртықтар / Шрамов / Scars с
  выбором результата броском `d12`.
