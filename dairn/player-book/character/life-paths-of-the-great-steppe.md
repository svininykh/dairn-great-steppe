# Жизненные пути Великой Степи


Этот справочный блок предназначен для полных игровых статей Жизненного
пути, доступных при создании персонажа DAIRN. Утверждённый перечень приведён в
[таблице Жизненного пути](../../tables/life-path-d20.md).

Каждый Жизненный путь разрабатывается по единому рабочему шаблону:

1.  **Название Жизненного пути.**
2.  **Кем был персонаж** до начала Приключений.
3.  **Опыт и знания**, которые очевидно следуют из этого Жизненного пути.
4.  **Варианты имени** или ссылка на подходящую таблицу имён.
5.  **Уникальный элемент Жизненного пути.**
6.  **Индивидуальная особенность Жизненного пути**, если она нужна.
7.  **Узы с людьми, местами или событиями Великой Степи.**

Перечень Жизненных путей является оригинальным материалом DAIRN. Этот
блок сохраняет игровую функцию Background из Cairn 2e, но не переносит
его сеттинговый перечень.

Общая начальная Поклажа определяется по отдельной
[таблице `6d6`](../../tables/starting-inventory-6d6.md), а уникальные
элементы Жизненных путей — по
[таблице `d20`](../../tables/life-path-unique-elements-d20.md).
