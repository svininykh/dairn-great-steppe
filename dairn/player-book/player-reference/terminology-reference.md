# Терминологическая памятка


Краткая выборка наиболее часто используемых терминов из
актуальной [Терминологической базы DAIRN](../../glossary.md) в порядке:

**Қазақша / Русский / English**

Полная терминологическая база остаётся отдельным рабочим документом
проекта и не должна автоматически целиком переноситься в книгу игрока.
