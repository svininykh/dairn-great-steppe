# Формат истории DAIRN

SPDX-License-Identifier: Apache-2.0

Спецификация `story.yaml`, версия `0.2`. История объединяет
[Markdown-главы](DAIRN_CHAPTER_FORMAT.md) и их иллюстрации.
Ссылка на её манифест задаётся в [`book.yaml`](DAIRN_BOOK_PACKAGE.md).

## Манифест истории

Создайте `story.yaml` в каталоге истории. Минимальный пример:

```yaml
story-id: journey
story-version: 0.2
start-chapter: chapter-01
chapters:
  - id: chapter-01
    source: chapters/chapter-01.ru.md
```

Все поля примера обязательны:

| Поле | Что записать |
| --- | --- |
| `story-id` | Стабильный ID, совпадающий со ссылкой в `book.yaml`. |
| `story-version` | `0.2` — версия формата, не редакция текста или пакета. |
| `start-chapter` | ID начальной главы из списка `chapters`. |
| `chapters` | Главы с уникальными `id` и путём `source` для каждой. |

Пути глав и изображений относительны каталогу истории.
Список глав сам по себе не задаёт переходов между ними;
[способ завершения главы](DAIRN_CHAPTER_FORMAT.md#переходы-и-завершение)
пока остаётся открытым вопросом.

Сохраняются описательные поля истории `title`, `form`, `status`,
`planned-chapters` и главы `title`, `status`. Публикационный `status`
не означает завершение игровой сессии; новые наборы значений этих полей
здесь не определяются.

## Обложки историй и иллюстрации глав

Обложка и иллюстрации необязательны. Пример дополнения к манифесту:

```yaml
cover: artwork/cover.png
chapters:
  - id: chapter-01
    source: chapters/chapter-01.ru.md
    illustration: artwork/chapters/chapter-01.png
```

| Поле | Изображение | Путь относительно |
| --- | --- | --- |
| `book.yaml` → `cover` | Обложка книги | Каталога книги |
| `story.yaml` → `cover` | Обложка истории | Каталога истории |
| `chapters[].illustration` | Иллюстрация главы | Каталога истории |

Рекомендуемые пути показаны в примере. Можно использовать одно изображение
повторно; обложка истории не обязана совпадать с иллюстрацией первой главы.

## Переводы и другие материалы

При переводе сохраняйте ID сцен, выборов и целей переходов, меняя текст
и заголовки. Движок выбирает язык явно или по документированному правилу
выбора запасного языка.

`canon/` хранит сведения о мире, персонажах, тоне, начальных знаниях
и ограничениях ИИ; `memory/events.yaml` — ID и описания событий.
Они дополняют текст глав. Данные персонажей описаны в
[отдельном справочнике](CHARACTER_INITIAL_STATE.md).

[Границы формата и движка](README.md#что-определяет-формат) общие для всех
документов. Экспериментальные блоки не делают весь формат истории
экспериментальным. Спецификация распространяется по Apache-2.0;
содержимое книги сохраняет собственные лицензии.
